# SlotMap

`slot_map.h` is Sergey Makeev's SlotMap (https://github.com/SergeyMakeev/SlotMap,
MIT; the text is in `LICENSE` and at the top of the header), as the copy in
N64Recomp's RecompFrontend carries it. The port's `src/mod_data_api.cpp` keeps
the collections a mod asks for in it (`docs/MODS.md`).
